# Bybit Realtime Chart

Приложение для **мониторинга свечей Bybit Spot в реальном времени** с построением графика, линии справедливой цены (**фильтр Калмана**) и сигналов **mean reversion на процессе Орнштейна–Уленбека (OU)**.

---

## Что делает программа

1. Загружает последние **100 минутных свечей** через REST API Bybit.
2. Подключается к **WebSocket** и получает live-обновления текущей свечи.
3. Строит интерактивный график: **свечи**, **объём**, **SMA 5/10**, **линия Калмана**.
4. На каждой **закрытой** свече считает спред `close − fair_price` и обновляет **OU-модель** (z-score, сигнал BUY/SELL/FLAT/STOP).
5. Отображает статус OU в строке поверх графика Plotly.
6. Отправляет обновления в браузер через **Socket.IO** без перезагрузки страницы.

Пока минута не закрыта — свеча меняется по данным биржи. Когда приходит `confirm: true` — свеча фиксируется, фильтр Калмана и OU делают по одному шагу.

### Модули

| Файл | Роль |
|------|------|
| `main.py` | Точка входа, запуск WebSocket-потока и веб-сервера |
| `config.py` | Пара, таймфрейм, эндпоинты Bybit, параметры Калмана и OU |
| `data_collector.py` | Сбор данных, хранение свечей, Калман, OU, `get_render_data()` |
| `kalman_filter.py` | Оценка «справедливой цены» (уровень + тренд) |
| `ou_mean_reversion.py` | OU-процесс на спреде, z-score и торговые сигналы |
| `chart_builder.py` | Генерация графика Plotly на сервере |
| `web_server.py` | HTTP API, SocketIO, broadcast обновлений и `ou_status` |
| `template_manager.py` | Загрузка HTML-шаблонов |
| `templates/index.html` | Веб-интерфейс, отрисовка OU-строки через аннотацию Plotly |

### Потоки

- **Главный поток** — Flask/SocketIO (порт `5000`)
- **Фоновый поток** — WebSocket-клиент к Bybit (asyncio)
- Чтение свечей и оценок — под `RLock` в `data_collector` (атомарный `get_render_data()`)

## Настройки

Основные параметры в `config.py`:

| Параметр | Значение | Описание |
|----------|----------|----------|
| `SYMBOL` | `BTCUSDT` | Торговая пара |
| `TIMEFRAME` | `1` | Таймфрейм в минутах |
| `MAX_CANDLES` | `100` | Свечей на графике |
| `FLASK_PORT` | `5000` | Порт веб-сервера |
| `ENABLE_SMA_5/10` | `True` | Скользящие средние |
| `KALMAN_*` | см. config | Параметры фильтра Калмана |
| `OU_WINDOW` | `200` | Буфер спреда для OU |
| `OU_MIN_OBS` | `50` | Мин. наблюдений для оценки OU |
| `OU_ENTRY_Z` | `2.0` | Порог z-score для входа |
| `OU_EXIT_Z` | `0.5` | Порог z-score для выхода |
| `OU_STOP_Z` | `3.5` | Порог z-score для STOP |

## Как определяется закрытие свечи

Bybit присылает в push-сообщении kline поле **`confirm`**:

- `false` — свеча ещё формируется
- `true` — минута закрыта, OHLCV финальные

Ключ свечи — поле **`start`** (время открытия минуты), а не `timestamp` (время последней сделки).

## Результаты

- Live-график минутных свечей Bybit Spot, согласованный с данными биржи
- Обновление текущей свечи до закрытия минуты
- Линия справедливой цены (Калман) — один шаг на каждую **закрытую** свечу
- OU-стратегия mean reversion: z-score и сигнал (BUY / SELL / FLAT / STOP) на спреде `close − Kalman`
- Строка OU на графике Plotly, обновляется при каждом push; значения сигнала меняются при закрытии свечи
- Автопереподключение WebSocket при обрыве связи
- Статистика 24ч (high, low, volume) в интерфейсе

---

## Ограничения

- Рынок **Spot** (не Linear/Inverse фьючерсы)
- Подписка на **kline**, не на order book и не на поток каждой сделки
- Kline push от Bybit — с интервалом ~1–60 сек, не на каждое изменение стакана
- Калман, SMA и OU — дополнительные индикаторы; на стандартном UI Bybit их нет
- OU и Калман обновляются только на **закрытых** свечах, не внутри формирующейся минуты
- Сигналы OU отображаются в UI; автоторговля не реализована
