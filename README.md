# Bybit Realtime Chart + OU Demo Trader

Приложение для **мониторинга свечей Bybit Spot в реальном времени** с построением графика, линии справедливой цены (**фильтр Калмана**), сигналов **mean reversion на процессе Орнштейна–Уленбека (OU)** и **демо-торговлей** (эмуляция сделок по сигналам OU с виртуальным балансом).

---

## Что делает программа

1. Загружает последние **100 минутных свечей** через REST API Bybit.
2. Подключается к **WebSocket** и получает live-обновления текущей свечи.
3. Строит интерактивный график: **свечи**, **объём**, **SMA 5/10**, **линия Калмана**.
4. На каждой **закрытой** свече считает спред `close − fair_price` и обновляет **OU-модель** (z-score, сигнал BUY/SELL/FLAT/STOP).
5. По сигналам OU работает **демо-трейдер**: виртуально открывает и закрывает позиции (с учётом комиссии и проскальзывания), сделки отображаются маркерами на графике.
6. Отображает статус OU и статистику демо-трейдера в веб-интерфейсе.
7. Отправляет обновления в браузер через **Socket.IO** без перезагрузки страницы.

Пока минута не закрыта — свеча меняется по данным биржи. Когда приходит `confirm: true` — свеча фиксируется, фильтр Калмана, OU и демо-трейдер делают по одному шагу.

> ⚠️ Демо-трейдер **не отправляет ордера на биржу** — это симуляция с виртуальным балансом в USDT.

### Модули

| Файл | Роль |
|------|------|
| `main.py` | Точка входа, запуск WebSocket-потока и веб-сервера |
| `config.py` | Пара, таймфрейм, эндпоинты Bybit, параметры Калмана, OU и демо-трейдера |
| `data_collector.py` | Сбор данных, хранение свечей, Калман, OU, демо-трейдер, `get_render_data()` |
| `kalman_filter.py` | Оценка «справедливой цены» (модель локального линейного тренда: уровень + скорость) |
| `ou_mean_reversion.py` | OU-процесс на спреде (AR(1) через МНК), z-score и торговые сигналы |
| `demo_trader.py` | Эмулятор торговли по сигналам OU: позиции, PnL, комиссии, сохранение состояния |
| `chart_builder.py` | Генерация графика Plotly (свечи, SMA, объём, Калман, маркеры сделок) |
| `web_server.py` | HTTP API, SocketIO, broadcast обновлений, `ou_status` и `demo_status` |
| `template_manager.py` | Загрузка HTML-шаблонов |
| `templates/index.html` | Веб-интерфейс: график, OU-статус, панель демо-трейдера со сделками |
| `demo_trader_state.json` | Файл состояния демо-трейдера (создаётся автоматически) |

### Потоки

- **Главный поток** — Flask/SocketIO (порт `5000`)
- **Фоновый поток** — WebSocket-клиент к Bybit (asyncio)
- Чтение свечей, оценок Калмана, z-score и статусов — под `RLock` в `data_collector` (атомарный `get_render_data()`)

### Логика демо-трейдера

- **Вход** — при `|z| ≥ entry_z` и сигнале OU (`BUY` при z < 0, `SELL` при z > 0)
- **Выход** — при возврате `|z| ≤ exit_z` либо по стоп-лоссу `|z| ≥ stop_z`
- **Реверс** — закрытие и разворот позиции при противоположном сигнале
- Объём позиции — доля баланса (`position_size_pct`), учитываются комиссия (`fee_rate`) и проскальзывание (`slippage`)
- Состояние (баланс, сделки, открытая позиция) сохраняется в `demo_trader_state.json` и восстанавливается при перезапуске

## Как определяется закрытие свечи

Bybit присылает в push-сообщении kline поле **`confirm`**:

- `false` — свеча ещё формируется
- `true` — минута закрыта, OHLCV финальные

Ключ свечи — поле **`start`** (время открытия минуты), а не `timestamp` (время последней сделки).

Дополнительно: если новая свеча началась, а `confirm` по предыдущей не пришёл (потеря пакета), предыдущая свеча финализируется принудительно — Калман и OU всегда делают ровно один шаг на закрытый бар. Повторные `confirm` одной и той же свечи игнорируются.

## Веб-интерфейс

- **График**: свечи с z-score в подсказке (hover), SMA 5/10, объём, жёлтая линия Калмана
- **Маркеры сделок**: треугольники — входы (▲ BUY / ▼ SELL), круги — выходы (цвет по PnL), открытая позиция выделяется жёлтой обводкой
- **OU-статус**: z-score, сигнал, готовность модели
- **Панель демо-трейдера**: баланс, общий PnL, комиссии, число сделок, winrate, открытая позиция, список последних 10 сделок
- **Статистика 24ч**: high, low, volume

## Результаты

- Live-график минутных свечей Bybit Spot, согласованный с данными биржи
- Обновление текущей свечи до закрытия минуты
- Линия справедливой цены (Калман) — один шаг на каждую **закрытую** свечу
- OU-стратегия mean reversion: z-score и сигнал (BUY / SELL / FLAT / STOP) на спреде `close − Kalman`
- Демо-торговля по сигналам OU с виртуальным балансом, комиссиями и проскальзыванием
- Сохранение и восстановление состояния демо-трейдера между запусками
- Автопереподключение WebSocket при обрыве связи
- Статистика 24ч (high, low, volume) в интерфейсе

## Ограничения

- Рынок **Spot** (не Linear/Inverse фьючерсы)
- Подписка на **kline**, не на order book и не на поток каждой сделки
- Kline push от Bybit — с интервалом ~1–60 сек, не на каждое изменение стакана
- Калман, SMA и OU — дополнительные индикаторы; на стандартном UI Bybit их нет
- OU, Калман и демо-трейдер обновляются только на **закрытых** свечах, не внутри формирующейся минуты
- Демо-трейдер — **симуляция**: реальные ордера на биржу не отправляются
- z-score считается относительно нуля спреда (линии Калмана), а не долгосрочного среднего OU
