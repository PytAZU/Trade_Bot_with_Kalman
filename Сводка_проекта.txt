1. НАЗНАЧЕНИЕ
--------------------------------------------------------------------------------
Приложение получает данные по свечам с биржи Bybit (Spot), строит график
в реальном времени с минутным таймфреймом и отображает линию «справедливой
цены» на основе фильтра Калмана.

Пока свеча не закрыта (confirm=false), её OHLCV обновляется по push-сообщениям
от биржи. После закрытия минуты (confirm=true) свеча фиксируется в истории,
и фильтр Калмана делает один шаг вперёд.


2. АРХИТЕКТУРА
--------------------------------------------------------------------------------
Монолитное Python-приложение из нескольких модулей. Два потока выполнения:

  [Главный поток]          Flask + SocketIO — веб-сервер и связь с браузером
  [Фоновый поток]          WebSocket-клиент — получение live-свечей от Bybit

Структура модулей:

  main.py              — точка входа, оркестрация, запуск потоков
  config.py            — настройки (пара, таймфрейм, API, Калман, цвета)
  data_collector.py    — REST + WebSocket Bybit, хранение свечей, Калман
  kalman_filter.py     — одномерный фильтр Калмана (уровень + тренд)
  chart_builder.py     — построение графика Plotly (свечи, SMA, объём, Калман)
  web_server.py        — HTTP-маршруты, SocketIO, broadcast обновлений
  template_manager.py  — загрузка HTML-шаблонов из папки templates/
  templates/index.html — клиентский интерфейс (Plotly.js + Socket.IO)


3. ПОТОК ДАННЫХ
--------------------------------------------------------------------------------

  Старт приложения
       │
       ├─► REST GET /v5/market/kline  — загрузка ~100 последних свечей (один раз)
       │       └─► 99 закрытых → candles_data
       │       └─► 1 текущая     → current_candle
       │
       ├─► REST GET /v5/market/tickers — статистика 24ч (high, low, volume)
       │
       └─► WebSocket wss://stream.bybit.com/v5/public/spot
               └─► subscribe: kline.{interval}.{symbol}
               └─► push-сообщения → process_kline_data → _update_candle_data
                       │
                       ├─ confirm=false → обновление current_candle
                       └─ confirm=true  → _finalize_candle → история + Калман

  Обновление графика в браузере:
       _update_candle_data → broadcast_update()
       → get_render_data() (свечи + Калман атомарно)
       → chart_builder.build_chart()
       → SocketIO emit('chart_update') → Plotly.react в браузере


4. КЛЮЧЕВАЯ ЛОГИКА СВЕЧЕЙ
--------------------------------------------------------------------------------
  • Идентификатор свечи — поле start (время открытия минуты), НЕ timestamp
    (timestamp в push Bybit — время последней сделки внутри свечи).

  • confirm=false  — свеча формируется, Калман не обновляется.
  • confirm=true   — свеча закрыта, добавляется в историю, +1 шаг Калмана.

  • get_display_data() и get_kalman_estimates() синхронизированы по длине
    (обрезка до MAX_CANDLES), чтение под RLock через get_render_data().


5. ИСПОЛЬЗУЕМЫЕ ТЕХНОЛОГИИ
--------------------------------------------------------------------------------

  Язык и runtime:
    Python 3, asyncio, threading

  Биржа:
    Bybit API v5 (Spot) — REST + WebSocket public

  Backend:
    Flask              — HTTP-сервер
    Flask-SocketIO     — WebSocket для браузера
    websockets         — WebSocket-клиент к Bybit
    requests           — REST-запросы

  Аналитика и визуализация:
    NumPy              — матрицы фильтра Калмана
    Plotly             — серверная генерация JSON графика

  Frontend:
    Plotly.js          — отрисовка графика в браузере
    Socket.IO (client) — получение обновлений в реальном времени
    HTML / CSS / JS    — интерфейс (templates/index.html)

  Прочее:
    certifi, ssl       — безопасное подключение к Bybit


6. НАСТРОЙКИ ПО УМОЛЧАНИЮ (config.py)
--------------------------------------------------------------------------------
  SYMBOL         = BTCUSDT
  TIMEFRAME      = 1 мин
  MAX_CANDLES    = 100
  Рынок          = Spot
  FLASK_PORT     = 5000
  SMA            = 5 и 10 периодов (включены)
  KALMAN_DELTA_T = 1.0 (один шаг = одна свеча)


7. РЕЗУЛЬТАТЫ ВЫПОЛНЕНИЯ
--------------------------------------------------------------------------------
  ✓ Получение исторических свечей при старте через REST API
  ✓ Live-обновление текущей незакрытой свечи через WebSocket
  ✓ Корректное закрытие свечи по флагу confirm от биржи
  ✓ Свечной график + объём + SMA 5/10 в веб-интерфейсе
  ✓ Линия справедливой цены (фильтр Калмана) — один шаг на закрытую свечу
  ✓ Автопереподключение WebSocket при обрыве (задержка 5 сек)
  ✓ Корректное завершение через кнопку в UI или Ctrl+C

  Исправленные ошибки:
  • Использование timestamp вместо start → лишние «свечи» на каждую сделку
  • Дублирование текущей свечи из REST и WebSocket
  • Рассинхрон длины массивов свечей и Калмана → мигание жёлтой линии


8. ЗАПУСК
--------------------------------------------------------------------------------
  pip install flask flask-socketio plotly websockets requests numpy certifi urllib3

  python main.py

  Открыть в браузере: http://localhost:5000


9. ОГРАНИЧЕНИЯ
--------------------------------------------------------------------------------
  • Только Spot-рынок (не фьючерсы)
  • Подписка на kline, не на order book и не на каждую сделку отдельно
  • Push kline от Bybit приходит с интервалом ~1–60 сек (не непрерывный поток)
  • Окно графика — последние 100 свечей
  • Линия Калмана — расчётная, её нет на стандартном графике Bybit
